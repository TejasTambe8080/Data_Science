# 1️⃣ What is Probability?

Probability tells us:

> **How likely an event is to happen.**

Formula:

```text
Probability = Favorable Outcomes / Total Outcomes
```

[
P(E)=\frac{\text{Favorable Outcomes}}{\text{Total Outcomes}}
]

---

## Example: Dice Roll

Sample Space:

```text
S = {1,2,3,4,5,6}
```

Probability of getting 3:

```text
Favorable Outcomes = 1

Total Outcomes = 6
```

[
P(3)=\frac{1}{6}
]

```text
= 0.1667
= 16.67%
```

---

# 2️⃣ Sample Space

Definition:

> Collection of all possible outcomes.

### Dice

```text
S = {1,2,3,4,5,6}
```

Number of outcomes:

```text
n(S) = 6
```

### Coin

```text
S = {H,T}
```

Number of outcomes:

```text
n(S)=2
```

---

### Interview Answer

> Sample Space is the set of all possible outcomes of an experiment.

---

# 3️⃣ Event

Definition:

> An event is a subset of the sample space.

### Example

Dice:

```text
S={1,2,3,4,5,6}
```

Event A:

```text
Getting an even number

A={2,4,6}
```

Number of favorable outcomes:

```text
3
```

Probability:

[
P(A)=\frac{3}{6}
]

```text
= 0.5
```

---

# 4️⃣ Independent Events

Definition:

Two events are independent if:

> One event does not affect the other.

Example:

```text
Coin Toss
Dice Roll
```

Coin result does not affect dice result.

# 5️⃣ Conditional Probability

Definition:

Probability of A occurring given B has already occurred.

Example:

Class:

```text
50 Students

30 Boys

20 Girls

10 Girls Play Cricket
```

Question:

Probability that a student plays cricket GIVEN that the student is a girl.

Formula:

genui{"probability_statistics_learning_block_staging":{"type_id":"CONDITIONAL_PROBABILITY_DEFINITION"}}

Calculation:

[
P(Cricket|Girl)
===============

# \frac{10}{20}

0.5
]

```text
50%
```

Meaning:

> If we already know the student is a girl, there is a 50% chance she plays cricket.

# 6️⃣ Bayes Theorem

The most important probability formula in ML.

Definition:

> Update your belief when new evidence arrives.

Formula:

genui{"probability_statistics_learning_block_staging":{"type_id":"BAYES_THEOREM"}}

---

# Understanding the Formula

Suppose:

```text
A = Email is Spam

B = Email contains "FREE MONEY"
```

We want:

```text
P(Spam | Free Money)
```

Meaning:

> Probability email is spam given it contains "FREE MONEY".

Bayes uses:

1. Prior Probability

```text
P(Spam)
```

2. Evidence

```text
P(Free Money)
```

3. Likelihood

```text
P(Free Money | Spam)
```

To calculate:

```text
P(Spam | Free Money)
```
