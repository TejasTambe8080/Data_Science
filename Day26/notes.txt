🧠 PART 2 — NORMAL DISTRIBUTION (MOST IMPORTANT)
Definition

A symmetric bell-shaped distribution.

Characteristics:

✅ Mean = Median = Mode

✅ Symmetric

✅ Bell-shaped

Bell Curve
            /\
          /    \
        /        \
      /            \
____/                \____
Real Examples
Heights
IQ Scores
Exam Marks
Measurement Errors
Python Visualization
import numpy as np
import seaborn as sns

data = np.random.normal(
    loc=50,
    scale=10,
    size=1000
)

sns.histplot(data, kde=True)

Interview Favorite.

🧠 PART 4 — UNIFORM DISTRIBUTION
Definition

Every outcome has equal probability.

Example:

Rolling a fair dice.

1 2 3 4 5 6

All equally likely.

Python
data = np.random.uniform(
    low=0,
    high=10,
    size=1000
)

sns.histplot(data)
Industry Example

Randomized testing.

🧠 PART 5 — BINOMIAL DISTRIBUTION

Used when:

Only two outcomes exist.

Examples:

Success / Failure
Yes / No
Click / No Click

Example:

10 users see advertisement.

Probability of click:

0.3

Question:

How many clicks expected?

Python
data = np.random.binomial(
    n=10,
    p=0.3,
    size=1000
)
Industry Uses
Marketing
CTR Prediction
Customer Conversion
🧠 PART 6 — Z-SCORE (VERY IMPORTANT)
Definition

Measures how far a value is from the mean.

Formula:

Where:

x = value
μ = mean
σ = standard deviation
Example

Salary:

70000

Mean:

50000

SD:

10000

Z-score:

(70000-50000)/10000
= 2

Meaning:

2 standard deviations above average.

Python
from scipy.stats import zscore

df["zscore"] = zscore(df["salary"])
🚨 PART 7 — OUTLIER DETECTION USING Z-SCORE

Rule:

|Z| > 3

Usually considered outlier.

Example:

Salary = 500000

Likely outlier.

Python
df[
    abs(df["zscore"]) > 3
]
