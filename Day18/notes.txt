🧠 PART 1 — THEORY (INTERVIEW LEVEL)
🔹 What is an Outlier?

👉 Value far away from normal data

📌 Example:

Salaries: 30k, 40k, 50k, 5,00,000 ← outlier
🔹 Why Important?
Distorts analysis
Affects ML models
Gives wrong insights

🔹 Using IQR (INTERVIEW IMPORTANT)
Q1 = df["salary"].quantile(0.25)
Q3 = df["salary"].quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df["salary"] < lower) | (df["salary"] > upper)]
🛠️ PART 3 — HANDLING OUTLIERS
✅ Method 1: Remove
df = df[(df["salary"] >= lower) & (df["salary"] <= upper)]
✅ Method 2: Cap (Winsorization idea)
df["salary"] = df["salary"].clip(lower, upper)

👉 Interview tip:

Remove → when error
Cap → when valid but extreme
📉 PART 4 — SKEWNESS (VERY IMPORTANT)
🔹 What is Skewness?

👉 Data not symmetric

Right skew → long tail right
Left skew → long tail left
🔹 Check Skewness
df["salary"].skew()
🔧 PART 5 — TRANSFORMATIONS
🔹 Log Transform (IMPORTANT)
import numpy as np

df["salary_log"] = np.log(df["salary"])

👉 Used to:

Reduce skewness
Normalize data
