🧠 PART 1 — THEORY (INTERVIEW LEVEL)
🔹 What is a Feature?

👉 Input variable used in ML

Example:

Age
Salary
Department
🔹 What is Feature Engineering?

👉 Creating better features from raw data

👉 Example:

Date → Month
Salary → Salary Category
🔹 Why Important?
Improves model accuracy
Makes patterns clearer
Used in every ML pipeline
⚙️ PART 2 — FEATURE CREATION (IMPORTANT)
Example:
df["salary_category"] = df["salary"] > 50000
🔹 From Date (VERY IMPORTANT)
df["month"] = df["date"].dt.month
df["weekday"] = df["date"].dt.day_name()
🔤 PART 3 — ENCODING (VERY IMPORTANT)
🔹 Why Encoding?

👉 ML models need numbers, not text

🔹 Label Encoding
df["dept_encoded"] = df["dept"].astype("category").cat.codes
🔹 One-Hot Encoding
pd.get_dummies(df["dept"])

👉 Interview tip:

Label → ordinal
One-hot → categorical
