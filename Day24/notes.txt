🧠 PART 1 — RANGE
What is Range?

Difference between:

Maximum Value - Minimum Value

Formula:

Example

salary = [30000,40000,50000,60000]

Range:

60000 - 30000

Result:

30000
Python
max(salary) - min(salary)
Limitation

Uses only:

Max value
Min value

Ignores everything else.

🧠 PART 2 — VARIANCE
What is Variance?

Measures:

👉 Average squared distance from the mean.

Formula:

Meaning:

Higher Variance

👉 Data is widely spread

Lower Variance

👉 Data is tightly clustered

Python
import numpy as np

np.var(salary)
Industry Example

Dataset A:

[48,49,50,51,52]

Low Variance

Dataset B:

[10,20,50,80,90]

High Variance

🧠 PART 3 — STANDARD DEVIATION
What is Standard Deviation?

Square root of Variance.

Formula:

Why use it?

Because variance is in squared units.

Standard deviation brings it back to original units.

Python
np.std(salary)
Interpretation

Small SD

👉 Consistent data

Large SD

👉 Highly variable data

🧠 PART 4 — IQR (REVIEW)

We saw this in Day 18.

Formula:

Used for:

Outlier Detection
Distribution Analysis
Python
Q1 = np.percentile(data,25)

Q3 = np.percentile(data,75)

IQR = Q3 - Q1
